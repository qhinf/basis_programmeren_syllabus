Wat is het verschil tussen een enkele regel commentaar en een meerregelige commentaar in Python?

  • Een enkele regel commentaar begint met //, en een meerregelige commentaar met /* */.
  • Een enkele regel commentaar begint met #, en een meerregelige commentaar met """ of '''.
  • Een enkele regel commentaar begint met #, en een meerregelige commentaar met //.
  • Er is geen verschil; beide gebruiken #.

Wat is het verschil tussen een int en een float in Python?

  • Een int is een geheel getal, terwijl een float een decimaal getal is.
  • Een int is een tekst, terwijl een float een getal is.
  • Een int is een negatief getal, terwijl een float een positief getal is.
  • Er is geen verschil; beide zijn hetzelfde.
