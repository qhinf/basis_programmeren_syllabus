Vraag maar raak!

Eén persoon mag vragen stellen, de ander antwoord door met de ogen te knipperen. Probeer een woord te communiceren.

Algoritmisch denken

Letter voor letter?
A: 1x knipperen, B: 2x knipperen, C: 3x knipperen, ...

Problemen?

  • Veel knipperen. Hoe vaak bij het woord 'puzzel'?
  • Wat als je verkeerd hebt geteld?
  • Cijfers?
  • Punten, komma's, andere leestekens?

Aanpak: vraag "Wat is de eerste letter?", etc.

In tweetallen:

  1. Bedenk een slimme oplossing om te communiceren
  2. Probeer het uit met een woord, bijvoorbeeld: "leuk"
  3. Schrijf op een blaadje:
    • Het algoritme (hoe werkt het?)
    • Waarom is jullie algoritme beter?
    • Wanneer werkt jullie algoritme minder goed?

Efficiëntie

Welk algoritme is sneller? Meet het aantal vragen en aantal keer knipperen!

Bijvoorbeeld voor een 4-letter-woord:

  • Best case: AAAA, 4× knipperen
  • Worst case: ZZZZ, 104× knipperen
  • Dus gemiddeld: 54× knipperen...

Voor beide vier vragen.

Opfrisquiz

Wat is het doel van een return-statement in een functie?

  • Het stopt de uitvoering van de hele code.
  • Het geeft een waarde terug aan de plek waar de functie is aangeroepen.
  • Het print automatisch de output van de functie.
  • Het zorgt ervoor dat de functie geen argumenten nodig heeft.

Wat is het verschil tussen een enkele regel commentaar en een meerregelige commentaar in Python?

  • Een enkele regel commentaar begint met //, en een meerregelige commentaar met /* */.
  • Een enkele regel commentaar begint met #, en een meerregelige commentaar met """ of '''.
  • Een enkele regel commentaar begint met #, en een meerregelige commentaar met //.
  • Er is geen verschil; beide gebruiken #.

Wat is het resultaat van de volgende code?

                        
print(type(3 + 4.5))
  • <class 'int'>
  • <class 'float'>

Wat is het verschil tussen een int en een float in Python?

  • Een int is een geheel getal, terwijl een float een decimaal getal is.
  • Een int is een tekst, terwijl een float een getal is.
  • Een int is een negatief getal, terwijl een float een positief getal is.
  • Er is geen verschil; beide zijn hetzelfde.
